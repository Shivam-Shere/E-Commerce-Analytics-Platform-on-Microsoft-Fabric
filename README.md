# E-Commerce-Analytics-Platform-on-Microsoft-Fabric
End-to-End Medallion Architecture Design (Bronze → Silver → Gold)

*A Lakehouse-to-Dashboard pipeline that ingests monthly incremental Olist order files, refines them through Bronze → Silver → Gold layers using PySpark, curates them into a Fabric Data Warehouse, and surfaces KPIs through a Power BI semantic model — fully orchestrated and scheduled.*
