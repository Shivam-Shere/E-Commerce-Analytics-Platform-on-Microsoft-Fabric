## Last Refresh Date: (e.g., Last Refresh: 02 Aug 2026 02:52 PM)

1. Last Refresh = "Last Refresh: " & FORMAT(NOW(), "dd MMM yyyy hh:mm AM/PM")

2. Last Refresh = 
VAR RefreshTime = FORMAT(NOW(), "dd MMM yyyy hh:mm AM/PM")
RETURN
"Last Refreshed"
    & UNICHAR(10)
    & RefreshTime



Note: NOW() updates when the dataset refreshes (or when the report is recalculated in Desktop), so it represents the report's refresh time rather than the latest transaction date.
